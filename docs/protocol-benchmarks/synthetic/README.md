# Constructed protocol fixtures

These PDFs are **invented test documents, not real protocols**. Each is written in a different sponsor style and carries rules chosen to cover one group of scheduling behaviours. The expected schedules (`expected.json`) are derived by hand from those rules in `backend/tests/kit_bench/fixtures/`, never from the app's output. `hand-model.json` is a kit model written by hand for the same rules, used to check the schedule engine without any AI.

Regenerate with `python -m tests.kit_bench.build` (from `backend/`).
